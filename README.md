# DSA-Java-Practice-07
# Java Array Operations Utility

This Java program implements a variety of algorithms and utilities for performing common operations on arrays. These include reversing arrays, partitioning, subarray analysis, inversion counting, finding maximum product subarrays, identifying frequent elements, minimizing swaps, making arrays palindromic, and more.

---

## 🔧 Features

### ✅ Array Operations Included:
- **Reverse Array**
- **3-Way Partitioning** (Dutch National Flag problem)
- **Smallest Subarray Sum ≥ K**
- **Inversion Count**
- **Maximum Product Subarray**
- **Elements Appearing More Than N/K Times**
- **Minimum Swaps to Group Elements ≤ K**
- **Minimum Operations to Make Array Palindrome**
- **Longest Consecutive Subsequence (Sorted)**
